# Мой визуальный язык

Веб-сервис для начинающих иллюстраторов и художников. Помогает понять, какие художественные приёмы тебе близки.

Сервис устроен как курс из приёмов. На странице приёма ты читаешь справку, пробуешь приём сам в любом медиуме (на бумаге, в редакторе, на фото, в коллаже) или ускоряешься готовым промтом для нейросети, а потом отмечаешь, насколько этот приём — твой, по шкале от 1 до 5.

Аккаунтов и сервера нет. Прогресс хранится только в браузере (`localStorage`), изображения пользователя никуда не загружаются.

Стек: Vite, React, TypeScript, `react-router-dom` (HashRouter), обычный CSS с переменными, Vitest.

## Запуск на своём компьютере

Нужен Node.js 22 (версия записана в `.nvmrc`).

```bash
npm install
npm run dev
```

Открой адрес, который покажет терминал (обычно http://localhost:5173).

Другие команды:

- `npm test` — тесты модуля хранилища;
- `npm run build` — сборка в папку `dist`;
- `npm run preview` — посмотреть собранную версию.

## Публикация на GitHub Pages

Сайт публикуется автоматически при каждом пуше в ветку `main` (workflow `.github/workflows/deploy.yml`): GitHub Actions ставит зависимости, прогоняет тесты, собирает проект и выкладывает папку `dist`.

Один раз включи Pages в настройках репозитория:

1. Открой репозиторий на GitHub → **Settings** → **Pages**.
2. В разделе **Build and deployment** выбери **Source: GitHub Actions**.
3. Сделай пуш в `main` или запусти workflow вручную: **Actions** → **Deploy to GitHub Pages** → **Run workflow**.

Сайт появится по адресу `https://<имя-пользователя>.github.io/<имя-репозитория>/`. Ссылку видно в **Settings → Pages** и в логе деплоя.

Путь сайта (`base` в `vite.config.ts`) берётся из имени репозитория автоматически. Если нужен другой (например, свой домен), задай переменную репозитория `BASE_PATH` в **Settings → Secrets and variables → Actions → Variables**: `/` для домена или `/путь/` для подпапки.

## Как добавить новый приём

Код менять не нужно, достаточно дописать объект в `src/data/techniques.json` и положить картинку.

```json
{
  "id": "collage",
  "order": 2,
  "title": "Коллаж",
  "axis": "composition",
  "summary": "Главное описание, 1–2 предложения.",
  "history": "Откуда приём взялся, 1–3 предложения.",
  "task": "Задание.",
  "tips": ["Подсказка 1", "Подсказка 2"],
  "duration": "20–40 мин",
  "artists": [{ "name": "Имя художника", "note": "чем интересен" }],
  "promptIntro": "Текст над промтами.",
  "prompt": { "en": "Prompt in English…", "ru": "Промт на русском…" },
  "promptNote": "Текст под промтами.",
  "image": { "src": "examples/collage.webp", "alt": "Пример приёма «Коллаж»", "caption": "Пример приёма «Коллаж»" }
}
```

Правила:

- `id` — латиницей в kebab-case, он попадает в адрес страницы (`#/technique/collage`) и в сохранённый прогресс. Не меняй `id` у уже опубликованного приёма, иначе оценки людей к нему потеряются.
- `order` — номер приёма в курсе. Он показывается в шапке («приём 2 / 12»).
- `axis` — одна из осей: `color` (Цвет), `texture` (Фактура), `form` (Форма), `composition` (Композиция).
- `tips` — от двух до четырёх коротких подсказок.
- `image` можно не указывать: тогда вместо картинки будет рамка «Пример появится позже».

Общее число приёмов в курсе задаётся константой `COURSE_LENGTH` в `src/lib/techniques.ts`.

## Как добавить картинку-пример

Положи файл в `public/examples/` с именем `<id>.webp`, например `public/examples/collage.webp`, и укажи путь в поле `image.src`: `examples/collage.webp`. Подробнее — в [public/examples/README.md](public/examples/README.md).

## Где что лежит

```
src/
  data/techniques.json   — контент приёмов
  lib/storage.ts         — чтение и запись прогресса (+ storage.test.ts)
  lib/progress.tsx       — общий доступ к прогрессу для компонентов
  lib/theme.ts           — светлая и тёмная тема
  lib/techniques.ts      — список приёмов, подписи осей, COURSE_LENGTH
  components/            — шапка, подвал, переключатель темы, форма оценки и др.
  pages/                 — страница приёма и «Такого приёма нет»
  styles/tokens.css      — цвета, шрифты, отступы
public/examples/         — картинки-примеры
```

В `localStorage` используются два ключа: `my-visual-language:v1` (оценки и заметки) и `my-visual-language:theme` (выбранная тема).
