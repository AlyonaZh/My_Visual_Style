# Картинки-примеры

Сюда кладутся картинки-примеры к приёмам. Сервис показывает их на странице приёма под описанием.

## Правила

- **Имя файла:** `<id приёма>.webp`, например `glitch.webp` для приёма с `"id": "glitch"`.
- **Формат:** webp.
- **Размер:** ширина 2000 px.
- **Пропорция:** 16:7 или 16:9.

## Как подключить

В `src/data/techniques.json` у приёма укажи поле `image`. Путь пиши относительно папки `public/`, без косой черты в начале:

```json
"image": {
  "src": "examples/glitch.webp",
  "alt": "Пример приёма «Глитч»",
  "caption": "Пример приёма «Глитч»"
}
```

- `alt` — описание картинки для тех, кто её не видит;
- `caption` — подпись под картинкой.

Если файла ещё нет или он не загрузился, на странице будет рамка «Пример появится позже», вёрстка не сломается.
